# @vbel/records

Records for verifiable business events: a chain with payloads that may be withheld, a link codec, a verdict per record, selective disclosure and identity claims that travel with the chain. Domain-neutral; the schemas of what a record says are yours.

Part of VBEL: independently verifiable signed records with detectable changes and blockchain anchoring. See the repository readme for what that does and does not prove.

```bash
pnpm add @vbel/records
```
