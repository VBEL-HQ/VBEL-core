# @vbel/adapter-ethereum

LedgerAdapter implementation over Ethereum calldata transactions. Execution only — config is injected, never read from process.env here.

Part of VBEL: independently verifiable signed records with detectable changes and blockchain anchoring. See the repository readme for what that does and does not prove.

```bash
pnpm add @vbel/adapter-ethereum
```

Apache-2.0.
