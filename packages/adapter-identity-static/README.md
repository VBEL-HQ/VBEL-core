# @vbel/adapter-identity-static

IdentityResolver over a static, explicitly-configured trust registry. The trust root is the file itself — see src/static-registry.ts.

Part of VBEL: independently verifiable signed records with detectable changes and blockchain anchoring. See the repository readme for what that does and does not prove.

```bash
pnpm add @vbel/adapter-identity-static
```
