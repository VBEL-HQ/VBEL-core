# @vbel/adapter-identity-ledger

IdentityResolver over entity registrations carried in the ledger itself, rather than over a file the verifier has to be given separately.

Part of VBEL: independently verifiable signed records with detectable changes and blockchain anchoring. See the repository readme for what that does and does not prove.

```bash
pnpm add @vbel/adapter-identity-ledger
```
